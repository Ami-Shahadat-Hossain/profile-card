# Profile Card Portfolio

A modern, responsive profile card website with animated navigation and interactive features. Perfect for showcasing professional information, skills, and contact details.

## 🌐 Live Demo

[View Live Demo](https://ami-shahadat-hossain.github.io/profile-card/profile-card-shahadat.html)

## ✨ Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Animated Navigation** - Smooth transitions between sections
- **Interactive Elements**:
  - Tabbed navigation (About, Experience, Contact)
  - Rotating job titles
  - Social media links
  - Contact modal with multiple options
- **Professional Timeline** - Display work experience and education
- **Modern UI** - Clean design with gradients and shadows
- **Performance Optimized** - Fast loading with minimal dependencies

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, animations, gradients, responsive design
- **Vanilla JavaScript** - No frameworks or libraries
- **Google Fonts** - Jost & DM Sans fonts
- **UI Avatars** - Dynamic avatar generation
- **Unsplash** - Background images

## 📱 Sections

### 1. About

- Professional introduction

- Skills and technologies

- Social media links (LinkedIn, GitHub, Facebook, Discord, Instagram)

### 2. Experience

- Timeline of work experience and training

- Year-wise display of achievements

- Responsive timeline design

### 3. Contact

- Location, phone, and email details

- "Work Together" modal with contact options:

- Email (pre-filled template)

- WhatsApp (pre-filled message)

- LinkedIn (direct profile link)
